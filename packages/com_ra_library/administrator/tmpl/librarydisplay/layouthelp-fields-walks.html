Available Keywords

  • lf - returns a linefeed(lf) to move your text down one line
  • group - returns the name of the group running the walk
  • dowShortdd - returns the walk date in the format of Thu, 28th
  • dowShortddmm - returns the walk date in the format of Thu, 28th March
  • dowShortddmmyyyy - returns the walk date in the format of Thu, 28th March 2019
  • dowdd - returns the walk date in the format of Thursday, 28th
  • dowddmm- returns the walk date in the format of Thursday, 28th March
  • dowddmmyyyy- returns the walk date in the format of Thursday, 28th March 2019
  • datebadge - a coloured date tile showing the day number and short month, e.g. 28 MAR
  • datebadgedow - as datebadge with the day of the week above, e.g. THU 28 MAR
  • datebadgeday - a coloured date tile showing just the day number, e.g. 28
  • datebadgedowday - as datebadgeday with the day of the week above, e.g. THU 28
    For multi day events a small 'to ...' line with the end date is added to each badge. Colours can be changed with the CSS variables --ra-datebadge-bg and --ra-datebadge-fg
  • additionalNotes - the additional notes field
  • title - the title of the walk
  • description - the description of the walk

Meeting information

  • meet - returns the details of the meeting place, e.g. 9:45 at Somewhere or blank
  • meetTime - returns the time of the meeting or blank
  • meetPlace - returns the meeting place of the walk or blank
  • meetGR - returns the OS Grid Reference of the meeting place or blank
  • meetPC - returns the Postcode of the meeting place or blank
  • meetw3w - returns the what 3 words value or blank

Start information

  • start - returns the details of the start of the walk e.g. 10am at Somewhere or blank
  • startTime - returns the time of the start or blank
  • startPlace - returns the starting place name or blank
  • startGR- returns the OS Grid Reference of the starting place or blank
  • startPC - returns the Postcode of the starting place or blank
  • startw3w - returns the what 3 words value or blank

Walk information

  • difficulty - displays the distance of the walk together with the National and local grades
  • distance - the length of the walk in the form 5Mi / 8Km
  • nationalGrade - the national Grade with a link to a description of the grades
  • localGrade - the local grade of the walk
  • shape - the shape of the walk,e.g. linear, circular
  • ascent - the likely ascent, e.g. 305m / 1000ft
  • ascentMetres - the likely ascent in metres, e.g. 305
  • ascentFeet - the likely ascent in feet, e.g. 1000

Contact Information

  • contact - display the walks contact details, either the contact or leader together with there telephone numbers and a link to enable users to email the contact
  • contactname - the name of the contact as either the leader or contact
  • telephone or telephone1 - the first telephone number of the contact
  • telephone2 - the second telephone number of the contact
  • email or emaillink - a link to a form on ramblers.org.uk to allow email contact to the contact
